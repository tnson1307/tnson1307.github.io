Desktop · Mac

ShipCheck

Stamp it cleared before Apple stamps it rejected.

A Mac app that reads your real Xcode project and live App Store Connect data — then lists what will bounce the submission, on your machine, before review does.

  • Diffs IAP product IDs, Privacy Manifest, and age-rating answers
  • Keys stay in Keychain; no ShipCheck server, ever
  • CLI for CI so drift fails the build, not the submit
  • Swift
  • macOS
  • App Store Connect API
