よくある質問

よくある質問

集中は本当にずっと無料？

はい。集中セッションは無制限、すべての集中モード（ストリクト・ゆる・ホワイトリスト）、集中時間1枠、すべての履歴とグラフ、バックアップ、気分チェック、自作スライム1体はずっと無料です。Pro では集中時間の追加、最大3体のスライムチーム、自然の音の追加、休憩 & ラウンドの自由設定、限定のなかまが使えます。ほかの相棒は集中して集めたジェムでお迎えします。

集中時間とは？

毎日の時間帯を決めて、気が散るアプリを選びます。その時間帯の間は、Nomodoro を閉じていてもアプリはロックされたまま。集中セッションを終えると休憩の間だけ開き、また自動でロックされます。無料：毎日1枠、アプリ3つまで。Pro：選んだ曜日に最大5枠、アプリもカテゴリも無制限。Apple のスクリーンタイム API を使っていて、選んだ内容が iPhone の外に出ることはありません。

勉強中や仕事中にアプリをブロックできる？

はい、2つの方法があり、どちらも Apple のスクリーンタイムを使います。ホワイトリストモードは、集中セッション中に許可したアプリ以外をすべてブロック。集中時間は、選んだアプリを毎日決めた時間にロックし、セッションを終えたあとの休憩中だけ開きます。どちらも無料版で使えます。

Forest とのちがいは？

どちらも、スマホから離れるかわいい理由をくれるアプリです。Forest では集中している間に木が育ちます。Nomodoro では小さな相棒とスライムたちがそばにいて、終わると喜び、あきらめるとしょんぼり（やめるには3秒の長押し）、あなたの気分にも反応します。さらに Apple のスクリーンタイムで、セッション中や決めた時間に気が散るアプリをロックできます。集中は無制限、すべての集中モードが無料です。

ホワイトリストモードはどうやってアプリをブロックするの？

Apple のスクリーンタイム API を使います。許可するアプリを最大10個選ぶと、それ以外のアプリは集中セッション中だけブロックされ、終わると解除されます。選んだアプリの情報が iPhone の外に出ることはありません。

セッションを途中でやめられる？

はい。「終了」を3秒長押ししてください。長押ししている間は相棒が泣きはじめ、指をはなすと大喜びします。カウントアップのセッションは保存するか聞くだけです。

なかまとジェムって？

集中セッションを終えるとジェムがたまり、手描きの相棒をお迎えできます。Pro なら限定の5体（タピオカ、ドーナツ、こいぬ、カピバラ、りんご）がジェムなしで解放。それ以外の子は、みんな同じくジェムを集めてお迎えします。

どの Pro プランを選べばいい？

気軽に試したいなら月額を。年額はいちばんお得（毎月払うより約58%安い）で、7日間の無料体験つき。終了の2日前にお知らせします。ずっと使うと決めているなら、一度払うだけの買い切りがおすすめです。
